3. FIREBASE — МАЪЛУМОТ ВА ВОРИДШАВӢ
---------------------------------------------------------------------
Ҳамаи маълумот (дархостҳо, нархҳо, муштариён, коргарон, аксҳо) дар Firebase аст,
на дар GitHub. Нақшаи ройгон (Spark) барои ширкати шумо кифоя аст.

3.1 Воридшавӣ (Authentication)
    Firebase → Build → Authentication → Sign-in method. Бояд фаъол бошанд:
      - Google            (барои роҳбарон)
      - Email/Password    (барои коргарон; логини коргар дар дохил чунин аст:
                           логин@workers.auto-peshsaf.app)
      - Anonymous         (барои муштариён — ном ва WhatsApp)
    Authentication → Settings → Authorized domains. Бояд бошанд:
      - saidumarjo.github.io
      - (агар домени худро харед, масалан zapchast.tj — онро ҳам илова кунед)

3.2 Маълумот (Firestore Database)
    Firebase → Build → Firestore Database → Data. Коллексияҳо:
      settings   — номи ширкат, логотип, асъор, VAT, гурӯҳҳо (settings/app)
      admins     — роҳбарони иловагӣ (ҳар ҳуҷҷат = Gmail-и роҳбар)
      workers    — коргарон (ном, гурӯҳ, телефон, фоизи музд)
      staff      — пайванди ҳисоби коргар бо коргар
      customers  — муштариён
      sessions   — воридшавии муштариён
      requests   — дархостҳо (он чи муштарӣ мебинад)
      priv       — нархи харид, паставшикҳо, музди коргар (муштарӣ НАМЕБИНАД)
      photos     — аксҳо
      activity   — ҷадвали воридшавӣ/баромад
      presence   — кӣ ҳозир дар барнома аст
    Маслиҳат: дар ин ҷо дастӣ чизе нест накунед. Ҳама корро аз сайт кунед.

3.3 Қоидаҳо (Rules) — чӣ тавр Publish кардан
    1. Файли firestore.rules-ро кушоед, ҳамаи матнро нусха гиред.
    2. Firebase → Firestore Database → Rules.
    3. Матни кӯҳнаро пурра пок кунед, матни навро гузоред.
    4. Тугмаи Publish-ро пахш кунед.
    Агар баъд аз навсозии сайт коргар хатои «Сабт нашуд» ё «Пайвастшавӣ суст аст»
    бинад — аксаран қоидаҳо Publish нашудаанд.

3.4 Нусхаи эҳтиётии маълумот
    Сайт → панели Роҳбар → ⚙ Танзимот → «⬇ Нусхаи эҳтиётӣ гирифтан».
    Файли backup-....json зеркашӣ мешавад (дархостҳо, нархҳо, муштариён, коргарон,
    танзимот; аксҳо дар файл нестанд). Ҳар моҳ як бор гиред ва дар Google Drive
    нигоҳ доред.

5. РАВАНДИ КОР (ҚАДАМ БА ҚАДАМ)
---------------------------------------------------------------------
 1. Муштарӣ дархост мефиристад («Ном ва акс» ё «Танҳо кодҳо»),
    ё роҳбар бо тугмаи (+) аз номи муштарӣ мегузорад.
 2. Роҳбар масъул (коргар) таъин мекунад.
 3. Коргар «Ба кор гирифтан» → дар «Қисмҳо ва нарх» нархи ҳар қисмро менависад
    (+VAT 5%, агар код иваз шуд — «↻ Код иваз шуд») → «Ёфт шуд».
 4. Роҳбар нархи паставшикро интихоб мекунад, фоида мегузорад (+10/20/30/50%).
 5. Роҳбар нархро ба муштарӣ мефиристад (WhatsApp).
 6. Муштарӣ «Заказ» мекунад — ё роҳбар «✓ Муштарӣ қабул кард» -ро пахш мекунад.
 7. Роҳбар масъули заказро таъин мекунад.
 8. Масъули заказ: аз паставшик гирифтан → бастабандӣ → акси бор + номи карго,
    рақами карго, вазн (кг), рӯзи супоридан → «Ба карго супоридам».
 9. Роҳбар: «Ба муштарӣ фиристодан» (инвойс + карго + вазн + сана + пайванд).
10. Пардохти муштарӣ сабт мешавад (қисман ҳам мумкин; аз инвойс зиёд қабул намешавад).
11. Роҳбар музди коргарро муайян ва пардохт мекунад.
12. Фоидаи соф ва инвойс дар қадами охир нишон дода мешавад.

Қисматҳои панели роҳбар (менюи поён):
  Дархостҳо · Муштариён (ва Қарздорон) · (+) · Инвойсҳо · Ҳисобот · Одамон
  ⚙ Танзимот — дар боло (номи ширкат, логотип, асъор, курс, VAT, гурӯҳҳо,
  нусхаи эҳтиётӣ).
  Ҳисобот: Умумӣ · Воридшавӣ (кӣ кай дохил/баромад) · Коргарон · Паставшикҳо.
